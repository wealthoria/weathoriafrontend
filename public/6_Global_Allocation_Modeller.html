1. ಈ calculator ಏನು ಮಾಡುತ್ತದೆ

Global Allocation Modeller ಒಂದೇ ಒಂದು ಪ್ರಶ್ನೆಗೆ ಉತ್ತರ ಹುಡುಕುತ್ತದೆ — ನಿಮ್ಮ equity ಭಾಗದಲ್ಲಿ ಎಷ್ಟು ಪಾಲು ಅಂತರರಾಷ್ಟ್ರೀಯ (international) ಆಗಿರಬೇಕು?

ಈ ಪ್ರಶ್ನೆ ಕೇಳಲು ಸುಲಭ, ಉತ್ತರಿಸಲು ಕಷ್ಟ. ಕಾರಣ — ಅಂತರರಾಷ್ಟ್ರೀಯ investment ಸೇರಿಸಿದಾಗ ಮೂರು ವಿಷಯಗಳು ಒಟ್ಟಿಗೆ ಬದಲಾಗುತ್ತವೆ:

  • ನಿರೀಕ್ಷಿತ return ಬದಲಾಗುತ್ತದೆ (ಸಾಮಾನ್ಯವಾಗಿ ಸ್ವಲ್ಪ ಕಡಿಮೆ ಆಗುತ್ತದೆ, ಏಕೆಂದರೆ US/global equity return ನಿರೀಕ್ಷೆ ಭಾರತಕ್ಕಿಂತ ಕಡಿಮೆ)
  • Volatility ಬದಲಾಗುತ್ತದೆ (correlation 1 ಗಿಂತ ಕಡಿಮೆ ಇರುವುದರಿಂದ ಕಡಿಮೆ ಆಗುತ್ತದೆ)
  • Currency ಒಂದು ಹೊಸ ಆಯಾಮ ಸೇರಿಸುತ್ತದೆ — ರೂಪಾಯಿ ದುರ್ಬಲವಾದರೆ ನಿಮ್ಮ ವಿದೇಶಿ holding ರೂಪಾಯಿಯಲ್ಲಿ ಹೆಚ್ಚಾಗುತ್ತದೆ

ಈ ಮೂರೂ ಒಟ್ಟಿಗೆ ಸೇರಿದಾಗ ಏನಾಗುತ್ತದೆ ಎಂಬುದನ್ನು ತಲೆಯಲ್ಲಿ ಲೆಕ್ಕ ಹಾಕುವುದು ಅಸಾಧ್ಯ. Calculator ಅದನ್ನೇ ಮಾಡುತ್ತದೆ.

ಮುಖ್ಯ ವ್ಯತ್ಯಾಸ

ಬಹಳಷ್ಟು allocation calculator ಗಳು ಕೇವಲ return ಮತ್ತು SD ತೋರಿಸಿ ನಿಲ್ಲುತ್ತವೆ. ಈ tool ಅದನ್ನು ನಿಜವಾದ ನಿವೃತ್ತಿ ಫಲಿತಾಂಶಕ್ಕೆ ಅನುವಾದಿಸುತ್ತದೆ — ಏಕೆಂದರೆ "Sharpe 0.28 ರಿಂದ 0.31 ಕ್ಕೆ ಏರಿತು" ಎಂಬುದಕ್ಕಿಂತ "success rate 84% ರಿಂದ 89% ಕ್ಕೆ ಏರಿತು" ಎಂಬುದು ನಿಮಗೆ ಅರ್ಥವಾಗುತ್ತದೆ.

2. ಯಾವ ಸಮಸ್ಯೆ ಬಗೆಹರಿಸುತ್ತದೆ

ಸಮಸ್ಯೆ 1 — "International ಸೇರಿಸಿದರೆ return ಕಡಿಮೆ ಆಗುತ್ತದೆ" ಎಂಬ ಅರ್ಧ ಸತ್ಯ

ಬಹಳ ಜನ ಹೀಗೆ ಯೋಚಿಸುತ್ತಾರೆ: "ಭಾರತೀಯ equity 12% ಕೊಡುತ್ತದೆ, US equity 8% ಕೊಡುತ್ತದೆ. ಹಾಗಾದರೆ US ಏಕೆ ಸೇರಿಸಬೇಕು? Return ಕಡಿಮೆ ಆಗುತ್ತದೆ ಅಲ್ಲವೇ?"

ಇದು arithmetic mean ದೃಷ್ಟಿಯಿಂದ ಸರಿ. ಆದರೆ ಎರಡು ವಿಷಯ ಬಿಟ್ಟುಹೋಗಿದೆ:

  • Currency — 8% US return ಡಾಲರ್‌ನಲ್ಲಿ. ರೂಪಾಯಿ ವರ್ಷಕ್ಕೆ 3% ದುರ್ಬಲವಾದರೆ ನಿಮಗೆ ಸಿಗುವುದು 8% ಅಲ್ಲ, ಸುಮಾರು 11.24%.
  • Volatility drag — ನೀವು ನಿಜವಾಗಿ ಪಡೆಯುವುದು arithmetic mean ಅಲ್ಲ, geometric return. SD ಹೆಚ್ಚಾದಷ್ಟೂ geometric return arithmetic ಗಿಂತ ಹೆಚ್ಚು ಕೆಳಗೆ ಬೀಳುತ್ತದೆ. Diversification SD ಕಡಿಮೆ ಮಾಡಿದರೆ ಈ drag ಕಡಿಮೆ ಆಗುತ್ತದೆ — ಅಂದರೆ mean ಕಡಿಮೆ ಆದರೂ geometric ಹೆಚ್ಚಾಗಬಹುದು.

Calculator ಈ ಎರಡನ್ನೂ ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಸೇರಿಸುತ್ತದೆ. ಆದ್ದರಿಂದ "intlShare ಹೆಚ್ಚಿಸಿದರೆ geometric return ಏರುತ್ತದೆಯೇ?" ಎಂಬ ಪ್ರಶ್ನೆಗೆ ನಿಜವಾದ ಉತ್ತರ ಸಿಗುತ್ತದೆ.

ಸಮಸ್ಯೆ 2 — Correlation ಎಷ್ಟು ಮುಖ್ಯ ಎಂದು ಗೊತ್ತಿಲ್ಲದಿರುವುದು

"Diversification ಒಳ್ಳೆಯದು" ಎಂಬುದು ಎಲ್ಲರಿಗೂ ಗೊತ್ತು. ಆದರೆ ಎಷ್ಟು ಒಳ್ಳೆಯದು ಎಂಬುದು correlation ಮೇಲೆ ಸಂಪೂರ್ಣ ಅವಲಂಬಿತ.

  • Correlation 0.9 ಆದರೆ — diversification ಬಹುತೇಕ ವ್ಯರ್ಥ. ಎರಡೂ ಒಟ್ಟಿಗೆ ಬೀಳುತ್ತವೆ.
  • Correlation 0.4 ಆದರೆ — ಗಣನೀಯ SD ಕಡಿತ ಸಿಗುತ್ತದೆ.
  • Correlation 0 ಆದರೆ — ಗರಿಷ್ಠ ಲಾಭ.

ಸಮಸ್ಯೆ ಏನೆಂದರೆ correlation ಸ್ಥಿರವಲ್ಲ. ಶಾಂತ ಕಾಲದಲ್ಲಿ 0.3 ಇರಬಹುದು, crisis ನಲ್ಲಿ 0.8 ಆಗಬಹುದು. Calculator ಈ ಸಂಖ್ಯೆಯನ್ನು ನೀವೇ ಬದಲಾಯಿಸಲು ಬಿಡುತ್ತದೆ — ಆದ್ದರಿಂದ "correlation 0.4 ಬದಲು 0.7 ಆದರೆ ನನ್ನ ನಿರ್ಧಾರ ಬದಲಾಗುತ್ತದೆಯೇ?" ಎಂದು ಪರೀಕ್ಷಿಸಬಹುದು.

ಸಮಸ್ಯೆ 3 — Currency risk ಅನ್ನು ತಪ್ಪಾಗಿ ಅರ್ಥ ಮಾಡಿಕೊಳ್ಳುವುದು

ಭಾರತೀಯ investor ಗೆ ವಿದೇಶಿ equity ಎರಡು risk ಒಟ್ಟಿಗೆ ಕೊಡುತ್ತದೆ — equity risk ಮತ್ತು currency risk. ಆದರೆ ಇವು ಸೇರಿದಾಗ ಒಟ್ಟು risk ಕೂಡಿಸಿದಷ್ಟು ಆಗುವುದಿಲ್ಲ — correlation ಋಣಾತ್ಮಕ ಆದರೆ ಕಡಿಮೆ ಆಗುತ್ತದೆ.

ಐತಿಹಾಸಿಕವಾಗಿ US equity ಬಿದ್ದಾಗ ಡಾಲರ್ ಬಲಗೊಳ್ಳುವ ಪ್ರವೃತ್ತಿ ಇದೆ (flight to safety). ಅಂದರೆ ರೂಪಾಯಿ ದುರ್ಬಲವಾಗುತ್ತದೆ — ಇದು ನಿಮ್ಮ ನಷ್ಟವನ್ನು ಭಾಗಶಃ ತುಂಬಿಕೊಡುತ್ತದೆ. ಈ ಸಂಬಂಧವನ್ನೇ corrIntlINR field ಹಿಡಿಯುತ್ತದೆ (default −0.15).

ಗಮನಿಸಿ

ಈ ಋಣಾತ್ಮಕ correlation ಒಂದು ಸಣ್ಣ ಆದರೆ ನಿಜವಾದ ಹೆಡ್ಜ್. ಇದನ್ನು 0 ಗೆ ಇಟ್ಟು ನೋಡಿ — international allocation ದ ಆಕರ್ಷಣೆ ಸ್ವಲ್ಪ ಕಡಿಮೆ ಆಗುತ್ತದೆ. +0.3 ಗೆ ಇಟ್ಟರೆ ಇನ್ನೂ ಕಡಿಮೆ.

ಸಮಸ್ಯೆ 4 — "ಎಷ್ಟು %" ಎಂಬುದಕ್ಕೆ ಯಾರೂ ಸ್ಪಷ್ಟ ಉತ್ತರ ಕೊಡುವುದಿಲ್ಲ

ಸಲಹೆಗಾರರು "10–30% international ಇರಲಿ" ಎನ್ನುತ್ತಾರೆ. ಈ ವ್ಯಾಪ್ತಿ ಎಲ್ಲಿಂದ ಬಂತು? ನಿಮ್ಮ ನಿರ್ದಿಷ್ಟ ನಿರೀಕ್ಷೆಗಳಿಗೆ ಅದು ಸರಿಯೇ?

Frontier tab ಈ ಪ್ರಶ್ನೆಗೆ ನೇರ ಉತ್ತರ ಕೊಡುತ್ತದೆ — ನಿಮ್ಮದೇ ಸಂಖ್ಯೆಗಳಿಂದ. ಮತ್ತು ಮುಖ್ಯವಾಗಿ ಅದು ತೋರಿಸುವುದು ಏನೆಂದರೆ — curve ಸಾಮಾನ್ಯವಾಗಿ ಬಹಳ ಚಪ್ಪಟೆಯಾಗಿರುತ್ತದೆ. 20% ಮತ್ತು 35% ನಡುವಿನ ವ್ಯತ್ಯಾಸ ಅಷ್ಟೇನೂ ದೊಡ್ಡದಲ್ಲ. ಇದೇ ಅತ್ಯಂತ ಉಪಯುಕ್ತ ಪಾಠ.

3. Core concept — Diversification ಮತ್ತು Currency

3.1 Variance ಕೂಡುವುದಿಲ್ಲ — ಇದೇ diversification ದ ಮೂಲ

ಎರಡು asset ಸೇರಿಸಿದಾಗ ಅವುಗಳ mean return ಸರಳವಾಗಿ ತೂಕದ ಸರಾಸರಿ ಆಗುತ್ತದೆ:

mean = wD × meanD + wI × meanI

ಆದರೆ variance ಹಾಗೆ ಆಗುವುದಿಲ್ಲ. ಅದಕ್ಕೆ correlation ಸೇರುತ್ತದೆ:

var = wD² × sdD² + wI² × sdI² + 2 × wD × wI × ρ × sdD × sdI ↑ ಇದೇ ಮಾಂತ್ರಿಕ ಪದ

ρ (correlation) 1 ಕ್ಕಿಂತ ಕಡಿಮೆ ಇದ್ದರೆ ಆ ಮೂರನೇ ಪದ ಚಿಕ್ಕದಾಗುತ್ತದೆ — ಪರಿಣಾಮವಾಗಿ ಒಟ್ಟು SD ತೂಕದ ಸರಾಸರಿಗಿಂತ ಕಡಿಮೆ ಆಗುತ್ತದೆ.

ಸಂಖ್ಯೆಯಲ್ಲಿ ನೋಡೋಣ

wD = 0.75, wI = 0.25, sdD = 20%, sdI = 17.1% (currency ಸೇರಿಸಿದ ನಂತರ), ρ = 0.4:

// ತೂಕದ ಸರಾಸರಿ SD (ತಪ್ಪು ಲೆಕ್ಕ, ಹೋಲಿಕೆಗಾಗಿ ಮಾತ್ರ) 0.75 × 20 + 0.25 × 17.1 = 19.28% // ನಿಜವಾದ variance ಲೆಕ್ಕ 0.75² × 20² = 0.5625 × 400 = 225.00 0.25² × 17.1² = 0.0625 × 292.4 = 18.28 2 × 0.75 × 0.25 × 0.4 × 20 × 17.1 = 51.30 ───────── var = 294.58 sd = √294.58 = 17.16%

ಅಂದರೆ 19.28% ಬದಲು 17.16%. 2.12 ಶೇಕಡಾ ಬಿಂದು ಉಚಿತವಾಗಿ ಸಿಕ್ಕ SD ಕಡಿತ. ಇದೇ diversification.

3.2 Volatility drag — ಏಕೆ SD ಕಡಿತ ಮುಖ್ಯ

ನೀವು ಪಡೆಯುವ ನಿಜವಾದ ಸಂಪತ್ತು arithmetic mean ಮೇಲೆ ಅಲ್ಲ, geometric return ಮೇಲೆ ಅವಲಂಬಿತ.

ಸರಳ ಉದಾಹರಣೆ

ಎರಡು ವರ್ಷ: +50%, ನಂತರ −50%. Arithmetic mean = 0%.

ನಿಜವಾಗಿ ₹100 → ₹150 → ₹75. ನಷ್ಟ 25%. Geometric return = −13.4% ವರ್ಷಕ್ಕೆ.

Arithmetic 0% ಆದರೂ ನೀವು ಕಳೆದುಕೊಂಡಿದ್ದೀರಿ. ಈ ಅಂತರವೇ volatility drag.

Drag ಸರಿಸುಮಾರು SD ದ ವರ್ಗಕ್ಕೆ ಅನುಪಾತದಲ್ಲಿ ಇರುತ್ತದೆ — ಅಂದರೆ SD 20% ರಿಂದ 17% ಕ್ಕೆ ಇಳಿದರೆ drag ಸುಮಾರು 28% ಕಡಿಮೆ ಆಗುತ್ತದೆ. ಇದೇ ಕಾರಣಕ್ಕೆ mean ಸ್ವಲ್ಪ ಕಡಿಮೆ ಆದರೂ geometric ಹೆಚ್ಚಾಗಬಹುದು.

3.3 Currency — ಗುಣಾಕಾರ, ಕೂಡಿಕೆ ಅಲ್ಲ

ಇದು ಬಹಳ ಜನ ತಪ್ಪು ಮಾಡುವ ಜಾಗ. ವಿದೇಶಿ return ಮತ್ತು ರೂಪಾಯಿ ಕುಸಿತ ಕೂಡುವುದಿಲ್ಲ, ಗುಣಿಸುತ್ತವೆ:

// ತಪ್ಪು ರೂಪಾಯಿ return = 8% + 3% = 11% // ಸರಿ ರೂಪಾಯಿ return = (1 + 0.08) × (1 + 0.03) − 1 = 1.08 × 1.03 − 1 = 1.1124 − 1 = 11.24%

ವ್ಯತ್ಯಾಸ 0.24 ಶೇಕಡಾ ಬಿಂದು — ಚಿಕ್ಕದು ಅನಿಸಬಹುದು. ಆದರೆ 30 ವರ್ಷ compound ಆದಾಗ ಇದು ಸುಮಾರು 7% ಹೆಚ್ಚು ಅಂತಿಮ ಸಂಪತ್ತು.

Code ನಲ್ಲಿ ಇದನ್ನು ವಿಸ್ತರಿಸಿ ಬರೆಯಲಾಗಿದೆ:

// (1+mf)(1+mc) − 1 ಅನ್ನು ವಿಸ್ತರಿಸಿದರೆ mean = mf + mc + mf × mc = 0.08 + 0.03 + 0.08 × 0.03 = 0.08 + 0.03 + 0.0024 = 0.1124 → 11.24%

ಆ ಮೂರನೇ ಪದ mf × mc ಚಿಕ್ಕದಾದರೂ ಬಿಡಬಾರದು. ಇದನ್ನೇ "cross term" ಎನ್ನುತ್ತಾರೆ.

3.4 Currency ಸೇರಿಸಿದಾಗ SD ಹೇಗೆ ಬದಲಾಗುತ್ತದೆ

ಎರಡು random variable ಗುಣಿಸಿದಾಗ variance ಲೆಕ್ಕ ಸಂಕೀರ್ಣ. Calculator ಒಂದು ಪ್ರಮಾಣಿತ ಅಂದಾಜು ಬಳಸುತ್ತದೆ:

variance = sf² + sc² + 2 × ρfc × sf × sc sf = ವಿದೇಶಿ equity SD (16%) sc = ರೂಪಾಯಿ SD (6%) ρfc = ಇವೆರಡರ correlation (−0.15)

Default ಸಂಖ್ಯೆಗಳಿಂದ:

16² = 256.00 6² = 36.00 2 × (−0.15) × 16 × 6 = −28.80 ──────── variance = 263.20 sd = √263.20 = 16.22%
ಗಮನಿಸಿ ಎಷ್ಟು ಸಣ್ಣ ಏರಿಕೆ

5. ಒಳಗಿನ Math — ಹಂತ ಹಂತವಾಗಿ

Default ಸಂಖ್ಯೆಗಳಿಂದ ಪೂರ್ಣ ಲೆಕ್ಕವನ್ನು ಆರು ಹಂತಗಳಲ್ಲಿ ಮಾಡೋಣ.

ಹಂತ 1 — ವಿದೇಶಿ equity ಅನ್ನು ರೂಪಾಯಿಗೆ ಪರಿವರ್ತಿಸಿ

// Input: intlReturn 8%, inrDep 3%, intlSD 16%, inrSD 6%, corrIntlINR −0.15 mf = 0.08 mc = 0.03 sf = 0.16 sc = 0.06 ρfc = −0.15 // Mean mean = mf + mc + mf×mc = 0.08 + 0.03 + 0.0024 = 0.1124 → 11.24% // Variance ಮತ್ತು SD var = sf² + sc² + 2×ρfc×sf×sc = 0.0256 + 0.0036 + 2×(−0.15)×0.16×0.06 = 0.0256 + 0.0036 − 0.00288 = 0.02632 sd = √0.02632 = 0.16224 → 16.22%

ಈಗ ವಿದೇಶಿ equity ರೂಪಾಯಿ ದೃಷ್ಟಿಯಿಂದ: mean 11.24%, SD 16.22%. ದೇಶೀಯ: mean 12%, SD 20%.

ಇಲ್ಲೇ ಪ್ರಮುಖ ಒಳನೋಟ

ರೂಪಾಯಿ ಪರಿವರ್ತನೆಯ ನಂತರ ವಿದೇಶಿ equity ದ return ದೇಶೀಯಕ್ಕಿಂತ ಕೇವಲ 0.76 ಶೇಕಡಾ ಬಿಂದು ಕಡಿಮೆ — ಆದರೆ SD 3.78 ಶೇಕಡಾ ಬಿಂದು ಕಡಿಮೆ. ಅಂದರೆ risk-adjusted ದೃಷ್ಟಿಯಿಂದ ವಿದೇಶಿ equity ಉತ್ತಮ. ಇದೇ ಕಾರಣಕ್ಕೆ frontier ಸಾಮಾನ್ಯವಾಗಿ ಗಣನೀಯ international ಪಾಲನ್ನು ಸೂಚಿಸುತ್ತದೆ.

// intlShare 25% → wI = 0.25, wD = 0.75 eqMean = 0.75 × 12.00 + 0.25 × 11.24 = 9.000 + 2.810 = 11.810% eqVar = wD²×sd² + wI²×si² + 2×wD×wI×ρ×sd×si = 0.5625×400 + 0.0625×263.2 + 2×0.75×0.25×0.4×20×16.224 = 225.000 + 16.450 + 48.672 = 290.122 eqSD = √290.122 = 17.033%

ಗಮನಿಸಿ: 100% ದೇಶೀಯ ಆಗಿದ್ದರೆ mean 12%, SD 20%. ಈಗ mean 11.81% (0.19 ಕಡಿಮೆ), SD 17.03% (2.97 ಕಡಿಮೆ). 0.19 ಬಿಟ್ಟುಕೊಟ್ಟು 2.97 ಪಡೆದಿದ್ದೀರಿ.

// equityAlloc 70% → we = 0.70, wb = 0.30 mean = we × eqMean + wb × debtReturn = 0.70 × 11.810 + 0.30 × 7.00 = 8.267 + 2.100 = 10.367% // ಗಮನಿಸಿ: equity ಮತ್ತು debt ನಡುವೆ correlation 0 ಎಂದು ಊಹಿಸಲಾಗಿದೆ sd = √(we² × eqSD² + wb² × debtSD²) = √(0.49 × 290.122 + 0.09 × 16) = √(142.160 + 1.440) = √143.600 = 11.983%
ಸರಳೀಕರಣದ ಬಗ್ಗೆ ಪ್ರಾಮಾಣಿಕತೆ

Code equity–debt correlation ಅನ್ನು ಶೂನ್ಯ ಎಂದು ಊಹಿಸುತ್ತದೆ. ವಾಸ್ತವದಲ್ಲಿ ಇದು ಸಾಮಾನ್ಯವಾಗಿ ಸ್ವಲ್ಪ ಋಣಾತ್ಮಕ (−0.1 ರಿಂದ −0.2) ಆಗಿರುತ್ತದೆ, ಆದರೆ inflation shock ಸಮಯದಲ್ಲಿ ಧನಾತ್ಮಕ ಆಗಬಹುದು. ಶೂನ್ಯ ಊಹೆ ಮಧ್ಯಮ ಮಾರ್ಗ. ಇದರಿಂದ portfolio SD ಸ್ವಲ್ಪ ಹೆಚ್ಚು ಅಥವಾ ಕಡಿಮೆ ತೋರಬಹುದು — ಆದರೆ ಎಲ್ಲಾ intlShare ಗೂ ಒಂದೇ ರೀತಿ, ಆದ್ದರಿಂದ ಹೋಲಿಕೆ ಸರಿಯಾಗಿಯೇ ಇರುತ್ತದೆ.

10. ಸಾಮಾನ್ಯ ತಪ್ಪುಗಳು

ತಪ್ಪು 1 — intlReturn ನಲ್ಲಿ ರೂಪಾಯಿ ಪರಿವರ್ತನೆ ಸೇರಿಸುವುದು

"US 8% ಕೊಡುತ್ತದೆ, ರೂಪಾಯಿ 3% ಬೀಳುತ್ತದೆ, ಆದ್ದರಿಂದ 11% ಹಾಕುತ್ತೇನೆ" — ಬೇಡ. Calculator inrDep ಅನ್ನು ಪ್ರತ್ಯೇಕವಾಗಿ ಸೇರಿಸುತ್ತದೆ. ನೀವು 11% ಹಾಕಿದರೆ ಅಂತಿಮವಾಗಿ 14.3% ಆಗುತ್ತದೆ — ಎರಡು ಬಾರಿ ಎಣಿಕೆ. ಆಗ frontier "100% international" ಎಂದು ತಪ್ಪು ಸಲಹೆ ಕೊಡುತ್ತದೆ.

ತಪ್ಪು 2 — ಐತಿಹಾಸಿಕ US return ಅನ್ನು ಭವಿಷ್ಯದ ನಿರೀಕ್ಷೆಯಾಗಿ ಬಳಸುವುದು

1980–2024 ರ US equity return ಅಸಾಧಾರಣ — valuation ಏರಿಕೆ, ಬಡ್ಡಿದರ ಕುಸಿತ, ಜಾಗತಿಕೀಕರಣ ಎಲ್ಲವೂ ಒಟ್ಟಿಗೆ ಸಹಾಯ ಮಾಡಿದವು. ಈಗ CAPE 30+ ಇರುವಾಗ ಅದೇ ಪುನರಾವರ್ತನೆ ನಿರೀಕ್ಷಿಸುವುದು ಅಪಾಯಕಾರಿ. 7–9% ಸಮಂಜಸ.

ತಪ್ಪು 3 — Correlation ಅನ್ನು ಸ್ಥಿರ ಎಂದು ನಂಬುವುದು

Model correlation ಸ್ಥಿರ ಎಂದು ಊಹಿಸುತ್ತದೆ. ವಾಸ್ತವದಲ್ಲಿ ಅದು crisis ದಲ್ಲಿ 0.85+ ಗೆ ಏರುತ್ತದೆ. ಆದ್ದರಿಂದ model ತೋರಿಸುವ downside protection ವಾಸ್ತವಕ್ಕಿಂತ ಸ್ವಲ್ಪ ಆಶಾವಾದಿ. ಸಂಪ್ರದಾಯಶೀಲ ಸಂಖ್ಯೆ ಬಳಸಿ.

ತಪ್ಪು 4 — Best Sharpe ಬಿಂದುವನ್ನು ಕುರುಡಾಗಿ ಅನುಸರಿಸುವುದು

Sharpe ratio arithmetic mean ಬಳಸುತ್ತದೆ, geometric ಅಲ್ಲ. ದೀರ್ಘಕಾಲದ ಸಂಪತ್ತು ಗರಿಷ್ಠಗೊಳಿಸಲು best-geometric ಬಿಂದು ಸರಿ. Best-Sharpe ಬಿಂದು ಸಾಮಾನ್ಯವಾಗಿ ಬಲಕ್ಕೆ ಇರುತ್ತದೆ (ಹೆಚ್ಚು intl) — ಅದು ಒಂದು ಬೇರೆ ಪ್ರಶ್ನೆಗೆ ಉತ್ತರ.

ತಪ್ಪು 5 — ತೆರಿಗೆ ಮತ್ತು fee ಮರೆಯುವುದು

ಭಾರತದಲ್ಲಿ international fund ದ ತೆರಿಗೆ ನಿಯಮ ದೇಶೀಯ equity fund ಗಿಂತ ಬೇರೆ ಮತ್ತು ಸಾಮಾನ್ಯವಾಗಿ ಪ್ರತಿಕೂಲ. Expense ratio ಕೂಡ ಹೆಚ್ಚು (0.5–1.5% vs 0.2%). Model ಇವನ್ನು ಸೇರಿಸಿಲ್ಲ. ವಾಸ್ತವ ಲಾಭ model ತೋರಿಸುವುದಕ್ಕಿಂತ ಕಡಿಮೆ ಇರುತ್ತದೆ.

ತಪ್ಪು 6 — ಪ್ರತಿ ಬಾರಿ seed ಬದಲಾಯಿಸಿ ಹೋಲಿಸುವುದು

ಎರಡು allocation ಹೋಲಿಸುವಾಗ seed ಒಂದೇ ಇರಬೇಕು. ಇಲ್ಲದಿದ್ದರೆ ವ್ಯತ್ಯಾಸ allocation ದಿಂದಲೋ Monte Carlo ದ ಶಬ್ದದಿಂದಲೋ ಗೊತ್ತಾಗುವುದಿಲ್ಲ. 1,500 path ನಲ್ಲಿ success rate ದ ಶಬ್ದ ಸುಮಾರು ±1 ಬಿಂದು.

ತಪ್ಪು 7 — ಒಂದೇ ಬಾರಿಗೆ ಇಡೀ ಬದಲಾವಣೆ ಮಾಡುವುದು

"30% ಸರಿ" ಎಂದು ನಾಳೆಯೇ 30% ಮಾರಿ ಖರೀದಿಸಬೇಡಿ. LTCG ತೆರಿಗೆ, exit load, ಮತ್ತು ಒಂದೇ ದಿನದ ಬೆಲೆಯ ಅದೃಷ್ಟ ಎಲ್ಲವೂ ವಿರುದ್ಧವಾಗಬಹುದು. 12–24 ತಿಂಗಳಲ್ಲಿ ಹರಡಿ.

ತಪ್ಪು 8 — Allocation ಅನ್ನು ಉಳಿತಾಯ ದರಕ್ಕಿಂತ ಮುಖ್ಯ ಎಂದು ಭಾವಿಸುವುದು
